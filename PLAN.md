# Шахматный тренер на C++ — полный план

Цель: программа для Windows (.exe) с графическим интерфейсом, которая учит играть в шахматы
и помогает поднять рейтинг на Lichess до 2000+. Внутри: боты разной силы, свой Elo с уровнями
(как на FACEIT), задачи, уроки, разбор партий, дебюты, эндшпили и статистика.

---

## 1. Технологии

| Что | Чем | Почему |
|---|---|---|
| Язык | C++20 | Быстро, собирается в один .exe |
| Сборка | CMake + MSVC (Visual Studio 2026 уже стоит) | Стандарт, зависимости качаются сами через FetchContent |
| Графика доски | raylib | Простая 2D-графика, анимации, звук |
| Меню, панели, графики | Свои виджеты на raylib (`src/ui/ui.cpp`) | Точно как в макетах, без лишних библиотек |
| Фигуры из SVG | nanosvg (`third_party/nanosvg`) | Растеризация под размер клетки — чёткие при любом окне |
| База данных | SQLite | Профиль, партии, рейтинг, история задач — в одном файле |
| Сильный анализ | Stockfish (отдельный stockfish.exe, протокол UCI) | Лучший бесплатный движок, для разбора ошибок и топ-ботов |
| Lichess | Открытый API через WinHTTP (встроен в Windows) | Импорт твоих партий без лишних библиотек |
| Задачи | Открытая база задач Lichess (CSV, берём ~50–100 тыс.) | Готовые задачи с рейтингом и темами |

## 1.1. Дизайн

**Раскладка экрана партии:** слева узкая панель навигации с иконками; в центре доска
с полоской оценки и плашками игроков (уровень, имя, Elo, часы); справа список ходов,
окно «Тренер» (наводящие подсказки, кнопки «Подсказка» / «Угрозы») и кнопки «Ничья» / «Сдаться».

**Темы интерфейса** (переключаются в настройках, по умолчанию «Ночь»):

| Тема | Стиль |
|---|---|
| Ночь | Тёмная, сине-серая, спокойная для долгих сессий |
| Дерево | Светлая классика, доска как настоящая |
| Арена | Чёрная с оранжевым, как на FACEIT |

**Наборы фигур** (переключаются в настройках отдельно от темы):

| Набор | Стиль | Автор | Лицензия |
|---|---|---|---|
| cburnett (по умолчанию) | Классика, как на Lichess | Colin M.L. Burnett | GPLv2+ |
| merida | Турнирная, как в книгах | Armando Hernandez Marroquin | GPLv2+ |
| alpha | Строгая, контрастная | Eric Bentzen | Бесплатно для личного некоммерческого использования |
| california | Мягкая, современная | Jerry S. | CC BY-NC-SA 4.0 |
| cardinal | Изящная, тонкие линии | sadsnake1 | CC BY-NC-SA 4.0 |
| maestro | Гладкая, плотная | sadsnake1 | CC BY-NC-SA 4.0 |
| staunty | Объёмная, под Стаунтон | sadsnake1 | CC BY-NC-SA 4.0 |
| tatiana | Рисованная | sadsnake1 | CC BY-NC-SA 4.0 |
| fantasy | Сказочная | Maurizio Monge | MIT |
| pixel | Пиксельная, ретро | therealqtpi | AGPLv3+ |
| letter | Буквы, для игры вслепую | usolando | AGPLv3+ |
| chessnut | Мультяшная, округлая | Alexis Luengas | Apache 2.0 |

- `governor` заменён на `chessnut`: у governor не указан автор и лицензия.
- Из-за лицензий NC (некоммерческие) программа бесплатная, не продаётся. Код проекта выкладываем под AGPLv3,
  чтобы совместить с GPL/AGPL-наборами.
- Для каждого набора храним автора и лицензию в `assets/pieces/<набор>/LICENSE`, на экране «О программе» список авторов.

**Окно выбора фигур (как в макете):** слева большая доска 8×8 в текущей теме с позицией из середины партии,
справа сетка карточек наборов (в каждой король, ферзь и конь обоих цветов + название).
Клик по карточке мгновенно ставит набор на доску-превью, под доской название и описание стиля.
Выбор применяется сразу и сохраняется. Если сменить тему или цвет доски, превью тоже обновляется.
- Формат: SVG → при запуске рендерим в текстуры под размер клетки, чтобы фигуры были чёткими при любом размере окна.
- Добавить свой набор: положить папку с 12 файлами (`wK.svg` … `bP.svg`) в `assets/pieces/`, программа подхватит сама.

**Доска:** отдельно выбирается цвет клеток (под тему или свой), координаты, стрелки и подсветка ходов.

**Анимации и звук:** плавное перемещение фигур, звуки хода, взятия, шаха, конца партии;
анимация +/− Elo и полоски уровня после партии.

## 3. Этапы

### Этап 1. Ядро шахмат
- Доска 8×8 (позже bitboards для скорости), все фигуры.
- Все правила: рокировка, взятие на проходе, превращение, шах, мат, пат,
  троекратное повторение, правило 50 ходов, недостаток материала.
- FEN (загрузка/сохранение позиции), PGN (партии), алгебраическая нотация (e4, Nf3, O-O).
- Тест perft: сверяем число позиций с эталоном. Если цифры сходятся, правила 100% верные.

**Результат:** движок правил без ошибок, проверенный тестами.

**Статус: готово.** `src/core/` + `tests/core_tests.cpp`: 87 проверок, perft совпадает с эталоном
на 6 позициях (≈15 млн позиций, < 1 с, ~19 млн позиций/с).

### Этап 2. Графический интерфейс
- Окно с доской, красивые фигуры, перетаскивание и клик-клик.
- Подсветка: последний ход, возможные ходы, шах.
- Анимация ходов, звуки (ход, взятие, шах).
- Окно выбора фигуры при превращении.
- Панель: список ходов, часы, кнопки (сдаться, ничья, перевернуть доску, назад).
- Главное меню: Играть / Обучение / Задачи / Анализ / Профиль / Настройки.

**Результат:** можно играть вдвоём на одном компьютере.

**Статус: готово.** `src/ui/`: меню, новая партия (7 контролей времени), экран партии (часы, ходы,
просмотр истории, отмена, ничья, сдача, сохранение PGN в ДокументыChessTrainergames), настройки
(3 темы, 6 цветов доски, 12 наборов фигур с превью, нотация RU/EN, звук). Стрелки правой кнопкой.
Звуки синтезируются кодом. Учтён масштаб экрана Windows. Настройки: %APPDATA%ChessTrainersettings.ini.

### Этап 3. Свой движок и боты
- Поиск: минимакс → альфа-бета → итеративное углубление, сортировка ходов,
  поиск взятий до «тихой» позиции (quiescence), таблица транспозиций.
- Оценка: материал, таблицы позиций фигур, безопасность короля,
  пешечная структура, активность, разная оценка в миттельшпиле и эндшпиле.
- **Личности ботов**, у каждого имя, рейтинг и стиль:

| Бот | Рейтинг | Характер |
|---|---|---|
| Новичок | ~400 | Часто зевает фигуры |
| Ученик | ~800 | Видит взятия, не видит вилок |
| Любитель | ~1100 | Нормальная игра, ошибается в тактике |
| Агрессор | ~1300 | Лезет в атаку на короля, жертвует |
| Позиционщик | ~1500 | Медленно давит, любит размены |
| Тактик | ~1700 | Ищет комбинации |
| Клубный | ~1900 | Крепкий универсал |
| Мастер | 2100+ | Stockfish с ограничением силы |
| Гроссмейстер | 2500+ | Stockfish почти на полную |

- Ослабление: глубина поиска, случайные неточности, «слепые зоны» (бот не видит некоторые тактики).

**Результат:** играешь против ботов любой силы.

**Статус: готово.** `src/engine/`: оценка (материал, таблицы фигур, пешки, король, подвижность, атака),
альфа-бета с итеративным углублением, таблицей позиций, взятиями до тихой позиции, продлением шахов,
сокращением поздних ходов; дебютная книга (30 линий). 8 ботов: Новичок 400, Ученик 700, Любитель 1000,
Агрессор 1200, Позиционщик 1400, Тактик 1600, Клубный 1800, Кандидат 2000 (рейтинги примерные —
уточним калибровкой со Stockfish). Мастер и Гроссмейстер — через Stockfish на этапе 5.
Проверено: тактика (мат в 1, вилка, 4 из 5 задач WAC), ~1–1.8 млн позиций/с, в матчах между собой
каждый следующий бот сильнее предыдущего. Бот думает в отдельном потоке, интерфейс не зависает.

### Этап 4. Elo и уровни как на FACEIT
- Твой рейтинг в программе. Старт: 5 калибровочных партий против ботов разной силы.
- После каждой партии пересчёт по формуле Elo:
  `новый = старый + K × (результат − ожидаемый)`,
  где `ожидаемый = 1 / (1 + 10^((Rбота − Rтвой) / 400))`.
  K = 40 первые 30 партий, потом 20.
- **Уровни 1–10** со значками и цветами:

| Уровень | Elo |
|---|---|
| 1 | до 600 |
| 2 | 600–800 |
| 3 | 800–1000 |
| 4 | 1000–1200 |
| 5 | 1200–1400 |
| 6 | 1400–1550 |
| 7 | 1550–1700 |
| 8 | 1700–1850 |
| 9 | 1850–2000 |
| 10 | 2000+ |

- Экран после партии: +/− очков, полоска прогресса до следующего уровня.
- Отдельный рейтинг задач (как на Lichess), растёт от решённых задач.
- График рейтинга по времени, серия побед, история партий.
- Режим «Подбор соперника»: бот выбирается под твой рейтинг автоматически.

**Результат:** есть понятный рейтинг и мотивация расти.

**Статус: готово.** `src/rating/elo.cpp` (формула Elo, K=40/20, калибровка по «перформансу» 5 партий,
уровни 1–10 с цветами FACEIT), `src/storage/profile.cpp` (SQLite: %APPDATA%\ChessTrainer\profile.db).
Рейтинговые партии — только с ботами; отмена хода делает партию тренировочной; меньше 2 ходов — не в счёт;
уход из рейтинговой партии (новая партия / выход) = поражение. После партии: значок уровня, +/− Elo,
полоса до следующего уровня, «Реванш». Профиль: уровень, статистика, серии, график рейтинга с полосами
уровней, последние партии. «Быстрая игра» подбирает бота под рейтинг. Рейтинг задач — на этапе 7.

**Доработка: режим «Рейтинговая игра».** Вместо «Быстрой игры» — отдельный режим: игрок выбирает только контроль
времени, соперника и цвет выбирает система (`App::findOpponent` → `rating::calibrationTarget` +
`engine::pickOpponent`; сюда же потом встанет Lichess). Калибровка 5 партий — бинарный поиск: старт 1200, шаг
±400/200/100/50 от рейтинга прошлого соперника; дальше сила = рейтинг ±100 случайно. Соперник — не бот из списка,
а отдельный бот под точное число (`engine::strengthBot`: шум, зевки, глубина и время смешаны между соседними
ботами 400–2000) со случайным стилем (Агрессор / Позиционщик / Тактик / Универсал); выше 2000 — Stockfish с UCI_Elo.

тренировочная партия. Старая причина, почему калибровка не шла: сохранённый режим «Тренер» молча делал
«Быструю игру» нерейтинговой.

### Этап 5. Stockfish и разбор партий
- Подключение stockfish.exe по UCI.
- После партии автоматический разбор: каждый ход получает оценку
  (отлично / хорошо / неточность / ошибка / зевок) по потере оценки в сантипешках.
- Шкала оценки сбоку доски, график партии.
- Лучший ход — синей стрелкой (слой подсказок `BoardView::setHintArrows` уже есть: сейчас он рисует
  оранжевую стрелку сыгранного хода при просмотре партии, листание ходов анимируется).
- Для ошибки показываем лучший ход и вариант («после твоего Bc4 был Nxe5 с выигрышем пешки»).
- Режим «Переиграй момент»: возвращаемся к ошибке и пробуешь найти лучший ход.
- Свободный анализ: расставить любую позицию и смотреть лучшие линии.

**Результат:** понимаешь, где и почему проиграл.

**Статус: готово.** Stockfish 17.1 (официальная сборка, GPLv3, `third_party/stockfish`, кладётся в `build/.../stockfish`).
`src/uci/` — общение по UCI, `src/analysis/` — фоновый разбор (250 мс на позицию), оценки ходов и точность
по формулам Lichess. Экран разбора: шкала оценки, график (клик — переход), оранжевая стрелка сыгранного
хода и синяя — лучшего, «Лучше было…», лучший вариант, «Ошибка ›» (следующая своя ошибка), «Найти ход лучше»
(проверка твоего хода Stockfish'ом). Разбор открывается после партии, из профиля (клик по партии), из меню
«Анализ» и вставкой PGN из буфера (партии с Lichess). Боты Мастер (2200) и Гроссмейстер (2600) — Stockfish
с UCI_Elo. Свободная расстановка позиции — позже.

**Оценки ходов как на chess.com: готово.** `analysis::reviewMoves` даёт 11 оценок: бриллиантовый (лучший/почти
лучший ход с жертвой фигуры, `isSacrifice`, после хода позиция не хуже равной), отличный (лучший ход, а второй
по силе хуже на 20+ % шансов; не простое взятие назад), лучший, превосходный, хороший, книжный (`engine::bookMoves`),
неточность, ошибка, упущенный выигрыш (было ≥80 % шансов, стало <65 %), зевок, вынужденный (единственный ход).
Stockfish считает в режиме MultiPV 2. `Analyzer` теперь дозаполняет оценки: при новом ходе пересчитывает только
новые позиции, поэтому разбор только что сыгранной партии открывается уже посчитанным. Значки (`src/ui/grades.*`):
цветной кружок с иконкой в углу клетки, куда пошла фигура, клетки хода подсвечены цветом оценки, появление с
«пружинкой», у бриллиантового и отличного — волны и вспышка. Показываются в разборе (доска, список ходов,
сводка по всем 11 оценкам у каждого игрока, подсказка с названием при наведении на значок) и в живой партии
(с ботом и вдвоём; анализ в фоне, 1 поток Stockfish, чтобы не мешать боту). Настройка «Оценки ходов во время
партии» (вкладка «Игра», `liveGrades` в settings.ini). Звук бриллиантового хода — файл `assets/sounds/ui/Brilliant.ogg`
(варианты лежат в `sound_previews/Бриллиантовый_*.mp3`, ставится после выбора).

### Этап 6. Тренер во время игры
- Режим обучения (можно выключить): перед зевком предупреждение «Подумай ещё, ты оставляешь фигуру без защиты».
- Показ угроз соперника по кнопке.
- Подсказки трёх уровней: «Есть тактика» → «Посмотри на коня» → показать ход.
- Партии в режиме тренера не идут в рейтинг.

**Результат:** бот учит прямо во время игры.

**Статус: готово.** `src/coach/` (проверка хода на зевок нашим движком, угрозы через `Position::attackers`,
3 уровня подсказок, причины, почему нет рокировки) + `src/ui/app_coach.cpp` (карточка «Тренер», окно
«Подумай ещё!» с «Переходить / Всё равно сходить», красные стрелки угроз, зелёные — подсказка).
Режим включается в «Новая партия»; партии с тренером не рейтинговые. Тесты тренера — в engine_tests.

### Этап 7. Задачи (тактика)
- База задач Lichess с рейтингом и темами (вилка, связка, мат в 2 и т.д.).
- Режимы: рейтинговые задачи, по темам, «штурм» на время, ежедневная задача.
- **Задачи из твоих ошибок:** каждый зевок из твоих партий становится задачей.
- Интервальное повторение: нерешённые задачи возвращаются через 1, 3, 7, 14 дней.

**Результат:** ежедневная тактика, главный способ поднять рейтинг.

**Статус: готово.** `src/training/`: 155 530 задач Lichess (CC0) в `assets/puzzles`, режимы «Рейтинговые»,
«По темам», «Задача дня», «Мои ошибки» (ошибки из анализа партий), «Повтор» (1/3/7/14 дней), «Штурм 3 мин».
Пройденные задачи хранятся в профиле, задачи не повторяются. Кнопка «Загрузить ещё задачи» один раз скачивает
полную базу Lichess (zstd, WinHTTP) и добавляет по 150 000 новых задач в `%APPDATA%\ChessTrainer\puzzles_more.csv`.

### Этап 8. Уроки (курс обучения)
Интерактивные уроки: объяснение + позиции на доске + задания «найди ход».

1. **Основы:** ценность фигур, мат ладьёй и ферзём, защита и атака фигур.
2. **Тактика:** вилка, связка, сквозной удар, вскрытый шах, двойной удар,
   отвлечение, завлечение, уничтожение защитника, промежуточный ход.
3. **Матовые конструкции:** мат по последней горизонтали, спёртый мат, мат Легаля, мат Анастасии и др.
4. **Дебютные принципы:** центр, развитие, рокировка, типичные ловушки.
5. **Миттельшпиль:** план, слабые поля, открытые линии, хорошие и плохие слоны, атака на короля.
6. **Эндшпиль:** оппозиция, правило квадрата, позиции Лусены и Филидора, ладейные и пешечные окончания.
7. **Мышление:** чек-лист перед ходом («шахи, взятия, угрозы»), работа со временем.

После каждого урока практика против бота в позиции из урока. Прогресс курса в профиле.

**Результат:** полноценная школа от 0 до ~1800.

**Статус: готово.** Курс в `assets/lessons/lessons.txt` (простой текстовый формат: `#` раздел, `=` урок, `@` позиция,
`>` стрелки, `?` решение, `!` пояснение после решения, `%` практика с ботом): 7 разделов, 23 урока, 26 заданий «найди ход».
Загрузчик — `src/training/lessons.cpp`, экран — `src/ui/app_lessons.cpp` (список курса с прогрессом и «Продолжить»,
урок: доска + объяснение + задание с подсказкой, ответ соперника, «Практика с ботом» из позиции урока, без рейтинга).
Задания проверяются тем же `PuzzleRun`, в последнем ходе засчитывается любой мат. Прогресс — в профиле
(`lesson:<id>`), строка «Уроки: X из Y» на экране профиля. Тест проверяет легальность всех позиций и решений;
каждое решение сверено со Stockfish (лучший ход). Партии теперь можно начинать из любой позиции (FEN, без дебютной книги).

### Этап 9. Дебюты
- Готовый репертуар на выбор (например: за белых 1.e4 Итальянская, за чёрных Каро-Канн и Ферзевый гамбит отказанный).
- Дерево вариантов с объяснениями каждого хода.
- Тренажёр с интервальным повторением: программа играет за соперника, ты вспоминаешь свои ходы.
- Свой репертуар: можно добавить ветки или загрузить из PGN.

### Этап 10. Эндшпили
- Набор ключевых позиций для отработки против бота: ферзь против короля,
  ладья против короля, пешка и король, Лусена, Филидор.
- Цель «выиграй за N ходов» или «удержи ничью».

**Статус: готово.** Раздел «Эндшпили» в меню: 8 позиций (`src/training/endgames.cpp`) — мат ферзём, мат ладьёй,
оппозиция (провести пешку), защита король против пешки, Лусена, Филидор, ферзь против пешки, пешечный прорыв.
Цели: мат за N, пешка в ферзи за N, удержать ничью N ходов. Соперник — Stockfish в полную силу (400 мс на ход),
он же после каждого хода оценивает позицию: выигрыш упущен (< +3) или защита проиграна (< −3) — провал сразу.
После провала — главная ошибка (ход с наибольшей потерей оценки, оценка до и после, стрелки: твой ход и лучший),
«Показать ошибку», «С ошибки», «Сначала». Пройденные — в профиле (`endgame:<id>`). Экран — `src/ui/app_endgames.cpp`.
Все позиции проверены Stockfish 17.1: легальны, выигрыши доигрываются движком против движка с запасом
(N ≈ 1,5× от хода движка), ничьи держатся 15 ходов с оценкой 0.

### Этап 10.5. Расширение курса уроков
Сейчас 24 урока и 30 задач — мало для закрепления. Текст остаётся коротким, растёт практика.
- В каждом уроке 4–5 задач от простой к сложной вместо 1–2.
- Новые разделы после «Мышления»:
  - Тактика 2: завлечение, отвлечение, перегрузка, промежуточный ход, рентген, мельница.
  - Ещё маты: арабский, Бодена, эполетный, греческий дар (Сxh7+).
  - Позиционная игра: пешечная структура (изолятор, сдвоенные, проходные), хороший и плохой слон,
    слабые поля, активность фигур, когда меняться.
  - Эндшпиль 2: ладейные (активная ладья, ладья позади проходной), ферзь против пешки,
    пешечный прорыв, треугольник, слон против коня.
  - Расчёт: ходы-кандидаты, счёт вариантов до конца, защита в плохих позициях.
- Цель — курс от новичка до ~1500–1700.
- Каждую задачу проверять Stockfish: легальность позиции и единственность решения.

**Статус: готово.** 12 разделов, 44 урока, 176 задач (по 4–5 в уроке). Новые задачи взяты из базы Lichess
(CC0) по темам и рейтингу, три старые неоднозначные задачи исправлены. Все задачи проверены Stockfish 17.1
(легальность, ход совпадает с движком, отрыв от второго хода ≥ 0.25 по шансам на победу); исключение —
ловушки Легаля и Блэкберна, где ход движка тот же, но отрыв меньше (дебютная демонстрация).

### Этап 11. Lichess
- Ввод ника, загрузка твоих партий через открытый API (без пароля).
- Массовый разбор всех партий через Stockfish.
- Отчёт: в каких дебютах проигрываешь, какие тактики пропускаешь,
  в какой фазе партии больше ошибок, сколько времени тратишь.
- Ошибки из Lichess-партий попадают в задачи (этап 7).

### Этап 12. Профиль и персональный план
- Дашборд: рейтинг в игре и в задачах, уровень, графики, слабые темы.
- **«Тренировка дня»**: программа сама собирает план на 30–60 минут
  (10 задач на слабую тему + повторение дебюта + 1 партия + разбор).
- Достижения и серии дней (стрик), чтобы не бросить.

**Статус: готово.** `src/storage/progress.cpp`: план дня, стрик, достижения (16 шт.), слабые темы; всё в SQLite-профиле
(ключи `plan`/`plan_day`, `streak*`, `ach:<id>`, счётчики `puzzles_solved`, `plans_done`). «План дня» в меню (широкая
карточка внизу сетки, прогресс и серия): 10 задач на слабую тему (по проваленным задачам, иначе тема дня), следующий
урок курса, эндшпиль (непройденный или по кругу), рейтинговая партия и её разбор (после партии) — около 55 минут.
План собирается один раз в день и сохраняется; пункты отмечаются сами через `App::progress(kind, arg)` из разделов.
Новый тип пункта (дебюты, Lichess) — строка в `storage::buildPlan` и ветка в `App::startPlanItem`. Профиль — вкладки
«Обзор» (рейтинг партий и задач, уровень, серия дней, прогресс уроков и эндшпилей, слабые темы и фазы ошибок
в разобранных партиях, график), «Партии», «Достижения». Тесты на план, стрик и достижения — в `rating_tests`.

### Этап 13. Полировка и релиз
- Темы доски и наборы фигур, настройки звука, полноэкранный режим.
- Сохранение и загрузка партий, экспорт в PGN.
- Сборка релиза: папка с .exe, stockfish.exe и данными. Позже, возможно, установщик.

**Установщик: готово.** Программа собирается со встроенными библиотеками MSVC (`/MT`), поэтому Visual C++
Redistributable не нужен. Установщик — Inno Setup, скрипт `installer/ChessTrainer.iss`: ставит без прав
администратора в `%LOCALAPPDATA%\Programs`, ярлыки в «Пуске» и (по желанию) на рабочем столе, удаление через «Приложения».
Сборка: `ISCC installer\ChessTrainer.iss` → `dist\ChessTrainer-Setup.exe`. Рядом `dist\ChessTrainer.zip` — та же папка архивом.
Версию установщик берёт из `build\version.iss`, его пишет CMake, так что перед ISCC нужен хотя бы один запуск cmake.

**Автообновление: готово.** Версия задаётся в одном месте: `project(ChessTrainer VERSION X.Y.Z)` в `CMakeLists.txt`,
оттуда она попадает в программу (`CHESS_VERSION`, видна в «Настройки → О программе») и в установщик.
При открытии меню программа в фоне спрашивает `api.github.com/repos/codegyry-crypto/chess-trainer/releases/latest`.
Если `tag_name` новее, вместо подзаголовка появляется плашка «Доступно обновление vX — Обновить». Кнопка скачивает
`ChessTrainer-Setup.exe` из релиза во временную папку, запускает его с `/VERYSILENT` и закрывает программу, а установщик
ставит новую версию поверх старой и сам её запускает. Без сети проверка молча ничего не показывает. Отключается в
«Настройки → Игра → Проверять обновления». Кто запускает программу из zip, получит при обновлении установленную версию
в `%LOCALAPPDATA%\Programs`.

**Как выпустить релиз:**
1. Поднять версию в `CMakeLists.txt`: `project(ChessTrainer VERSION 1.1.0 ...)`, закоммитить и запушить.
2. Поставить и запушить тег с той же версией: `git tag v1.1.0`, затем `git push origin v1.1.0`.
3. Дальше всё делает `.github/workflows/release.yml`: на windows-latest скачивает Stockfish 17.1, собирает Release,
   прогоняет тесты, собирает установщик (Inno Setup) и zip и публикует GitHub Release с обоими файлами.
   Если тег не совпадает с версией в CMake, сборка падает: иначе программа предлагала бы обновление по кругу.
4. Когда релиз появится, у всех, у кого стоит версия старше, при следующем запуске в меню появится плашка.

Этапы 1–4 дают играбельную программу с ботами и Elo. Это первая цель.

## 5. Параллельно для твоего рейтинга на Lichess

- Каждый день 20–30 минут тактики.
- Играть рапид 10+0 или 15+10, не буллет.
- Разбирать каждую проигранную партию.
- По мере готовности программы делать всё это в ней.
